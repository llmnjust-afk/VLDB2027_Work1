Title: Batch-Aware Parallel Maintenance of Exact k-Truss Decomposition on Dynamic Graphs

Abstract:
The k-truss decomposition assigns each edge the largest k for which the edge participates in at least k-2 triangles whose remaining edges are themselves k-trusses, and underlies community detection, community search, and temporal cohesive-subgraph analytics in social and transactional data platforms. The graphs behind these applications evolve continuously, so maintaining the exact decomposition under high-rate update streams is a first-class database problem. Existing exact maintenance algorithms process updates one edge at a time: each update triggers its own closure computation and its own traversal of the affected truss-connected region, so a burst of B co-located updates re-traverses the same dense community B times. We present the first batch-aware parallel algorithm for exact k-truss maintenance. For a batch of arbitrary interleaved insertions and deletions, the algorithm (i) maintains triangle witness counts in one parallel enumeration phase, (ii) computes a parallel mate closure that provably covers every edge whose trussness can change, and (iii) recomputes the affected region in a single Wang-Cheng peeling pass in which each boundary edge with unchanged trussness contributes an exactly-once virtual pop at its maintained peeling bucket. A differential-testing harness validates exactness against a static recomputation oracle after every batch. Experiments on eight public graphs (25K-69M edges) and 200K-update streams show per-batch costs 42-345x below sequential per-edge maintenance on dense-community graphs, an order of magnitude below full recomputation on graphs whose dense structure is localized, and parity with recomputation where every batch's recount touches the dense core or a hub set, while mapping the regime in which recomputation itself remains the right baseline.
